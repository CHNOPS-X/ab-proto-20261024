# 〈폴짝! 고무줄〉 T3 — 2D(A안) vs 3D(B안) 플레이 빌드

이 저장소에는 **빌드 산출물만** 들어 있다. 소스(`game.json`)·린터·테스트는 ORX 미션 저장소에 따로 있다.

## 바로 플레이
- 첫 화면(안내 + 두 빌드 링크): `index.html` — GitHub Pages 주소의 루트
- A안 2D: `2d/` · B안 3D: `3d/` (한 사이트 안의 두 경로라서 재시작 없이 번갈아 연다)

## 크기 (회차 5 재빌드, `metrics.json` 원본 동봉)
| 빌드 | raw B | gzip 합계 B | brotli 합계 B | 파일 | 린터 |
|---|---:|---:|---:|---:|---|
| 빈 내보내기 | 893,353 | 263,589 | 223,091 | 68 | error 0 |
| A안 2D | 1,006,435 | 295,203 | 250,709 | 79 | error 0 |

gzip·brotli는 파일마다 따로 압축해 더한 값이다. 실제 전송량이 아니다. `code0.js` sha256: 2D `629b538b…` · 3D `02f3a558…`.

## 키
`A`/`←` 왼발 · `D`/`→` 오른발 · `Space`/`Enter` 점프·시작 · `Esc` 일시정지 · `G` 안경 규격(600×600, 검정 배경, 고대비) 켜기/끄기 · `M` 길게 누르기↔토글 · `C` 오디오 시계 방식 · `P` 자동 시연 · `B` 블라인드 정지 장면.
폰: 왼쪽 35% 왼발 / 가운데 점프 / 오른쪽 35% 오른발. 맨 위 띠의 버튼 4개가 차례로 [G][M][C][P]다.

## 측정할 4가지
1. **예고 박자 수** — 위쪽 예고 레인. 노트가 판정선 5박 전에 나타난다. 몇 박 전에 다음 동작을 알았는가.
2. **높이 3단계 구별** — 가운데 무대의 줄 높이·말뚝 눈금·관절 기준선(0~11박 발목 · 12~23박 무릎 · 24~35박 높은 줄).
3. **줄 상태 가독성** — 기본 직선 · 한 발 걸기 V자 · 다리 꼬기 X자(6~7·18~19·30~31박) · 밟기.
4. **토글 on/off 차이** — `G`를 켰을 때 1~3이 달라지는가. `M` 토글에서 다리 꼬기 조작이 어떻게 달라지는가.

## 쿠키 로그와 린터
게임 번들 자체는 쿠키·`sharedId` 코드와 외부 요청을 넣지 않았다. `_gd…_sharedId` 거부 로그 4건은 Poki SDK가 연쇄 로드한 Prebid `sharedId` 모듈이 `127.0.0.1`을 4마디 도메인으로 탐색하며 생긴 기록이다. SDK 하나만 차단하면 쿠키 로그와 외부 호스트 요청이 0건이 된다.

린터의 `error 0`은 외부 요청 0건을 보증하지 않는다. R2는 정적 파일과 SDK URL 예외만 보고, `--initial-load`로 넘긴 런타임 외부 URL을 버리는 결함이 있다. R5는 `document.cookie`·`cookieStore` 검사도 누락했다.

## 확인하지 못한 것
실기 폰 브라우저 · 실기 GPU 3D 렌더링 · 실기 오디오 지연. 의장이 플레이한 결과로 채운다.
빌드에는 Poki SDK 태그가 들어 있다. github.io에서 SDK가 광고를 부르거나 "무단 호스팅" 경고를 내는지는 확인하지 못했다.
