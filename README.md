## 키 및 안경 규격 토글
- 키보드: `A`/`←` 왼발 · `D`/`→` 오른발 · `Space`/`Enter`/`↑` 점프·시작·재개 · `Esc` 일시정지/재개 · `R` 처음부터 재시작
- 상단 토글 띠(`y = 0~36px`, 터치 판정 `y ≤ 38px` 4등분 버튼):
  1. `G` (`[G]일반360` ↔ `[G]안경600²`): **안경 규격(600×600 정사각형 · `#000000` 순검정 배경 · 고대비 굵은 선) 켜기/끄기** (켜면 입력도 토글 탭 방식으로 자동 전환)
  2. `M` (`[M]홀드` ↔ `[M]토글탭`): 길게 누르기(홀드) ↔ 토글 탭(같은 발 한 번 더 누르면 풀기)
  3. `C` (`[C]OT시계` ↔ `[C]CT시계`): 오디오 시계 방식 전환(대기·일시정지·완료 상태에서만). 판정 문구(`y = 206px`)에 방식별 평균 오차(ms)가 표시됨
  4. `P` (`[P]수동` ↔ `[P]시연ON`): 자동 시연
  5. `B` (키보드로 진입, 진입 후 `B` 또는 화면 탭): 블라인드 정지 장면 6개(`B1`~`B6`, HUD·글자를 숨기고 높이·줄 상태만 표시)
- 폰 터치: `y > 38px` 게임 화면에서 왼쪽 35% 왼발 / 가운데 30% 점프 / 오른쪽 35% 오른발(두 손가락 교차 터치 독립 인식). 대기·일시정지·완료 상태에서는 `y > 38px` 아무 곳이나 탭하면 시작·재개.

## 측정할 4가지와 화면에서 볼 곳 (일반 360×640 기준)
1. **예고 박자 수** — 위쪽 노트 예고 타임라인(`y = 44~166px`, 가로 3줄: 왼발 청록 `y=70` · 점프 노랑 `y=105` · 오른발 분홍 `y=140`). 노트가 판정 **5박(2.5초) 전 오른쪽 끝에서 나타나 왼쪽 흰색 세로 판정선(`x = 76px`)으로 이동**한다. 몇 박 전에 다음 동작을 알았는가.
2. **높이 3단계 구별** — 가운데 무대(`y = 212~502px`, 지면 기준선 `y = 445px` / 안경 `425px`)의 줄 높이·좌우 기둥 눈금(`y = 317~453px`)·다리 관절 기준선(`T1-7C`). `0~11박` 1단 발목(초록) · `12~23박` 2단 무릎(주황/노랑) · `24~35박` 3단 높은줄(빨강). (`[B]` 블라인드 `B1`~`B6` 포함)
3. **줄 상태 가독성** — 가운데 무대의 고무줄(1단 초록·2단 주황/노랑·3단 빨강, 지면 그림자 갈색/청록)과 두 발(**왼발 청록/하늘색, 오른발 분홍/자홍**). 기본 직선 · 한 발 걸기 V자 굴절 · 다리 꼬기 4점 교차 굴절(`6~7·18~19·30~31박`, 왼발이 오른쪽으로 교차) · 밟기.
4. **토글 on/off 차이** — 맨 위 `[G]`를 켰을 때(600×600 순검정 고대비) 1~3이 달라지는가. `[M]` 토글에서 다리 꼬기 조작과 아래쪽 3분할 패드(`y = 558~626px`, 안경 `518~586px`; 걸기 유지 중 흰색 반전 + `줄 걸림 유지중!` 표시) 체감이 어떻게 달라지는가.

## 쿠키 로그와 린터
게임 번들 자체는 쿠키·`sharedId` 코드와 외부 요청을 넣지 않았다. `_gd…_sharedId` 거부 로그 4건은 Poki SDK가 연쇄 로드한 Prebid `sharedId` 모듈이 `127.0.0.1`을 4마디 도메인으로 탐색하며 생긴 기록이다. SDK 하나만 차단하면 쿠키 로그와 외부 호스트 요청이 0건이 된다.

린터의 `error 0`은 외부 요청 0건을 보증하지 않는다. R2는 정적 파일과 SDK URL 예외만 보고, `--initial-load`로 넘긴 런타임 외부 URL을 버리는 결함이 있다. R5는 `document.cookie`·`cookieStore` 검사도 누락했다.
