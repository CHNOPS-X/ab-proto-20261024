함대가 확인하지 못한 것 — 플레이 후 값을 돌려 달라

  • 실기 폰 브라우저 동작(두 손가락 동시 입력 포함)
  • 실기 GPU의 3D 렌더링
  • 실기 오디오 지연 — [C]로 두 방식을 한 판씩 하고 판정 문구의 평균 오차를 적어 달라

주의: 빌드 안에 Poki SDK 태그(Poki 제출 규격상 필수)가 그대로 있다. 이 사이트(github.io)에서 실측한 결과(2026-10-24, Firefox 158): SDK가 광고·지오 등 외부 호스트 10곳을 부르고, 콘솔에 "Unauthorized Game Hosting … DMCA" 경고를 낸다. 게임 진행은 막지 않는다. 곡이 끝나면 광고 시점 호출(commercialBreak)이 나간다. 폰 화면에 경고·광고가 실제로 보이는지는 확인하지 못했다. 게임 코드 자체는 외부 요청 0건이다(SDK를 막은 실측).

쿠키 거부 로그 4건은 게임 코드가 아니라 Poki SDK가 불러온 Prebid sharedId 모듈 기록이다. 린터 error 0은 외부 요청 0건을 보증하지 않는다: 런타임 외부 URL 검사 결함과 쿠키 API 검사 누락이 있다.
